# UE-003 — Escape menu and dummy flight controls

- Status: done
- Owner: Vision (runtime implementation); Milu (toolchain, launch/docs/evidence)
- Reviewer: Stark

## Scope

Add a compact Escape menu with Resume and Exit, and simple kinematic flight
controls for testing the Unreal cockpit. Preserve the scene, lighting fixes and
ultrawide vertical framing. These controls are intentionally not aerodynamic
simulation. Runtime gameplay must not rely on editor Python.

## Acceptance criteria

- Escape toggles the menu and pauses movement; Resume and Escape restore flight
  input and hide the cursor. Mouse input cannot leak into flight while paused.
- Clicking Exit terminates only the prototype game, with a normal quit request.
- Arrow pitch/bank, Q/E yaw, W/S throttle and R reset visibly work with bounded,
  delta-time movement. Reset restores the starting pose and speed.
- The menu remains readable and clickable at 1600x1000 and 3440x1440.
- Actual runtime behavior and menu images are checked; Stark reviews evidence.
- Launch and controls are documented for the user and future agents.

## Implementation and dependency outcome

User clarified that imposed plane states are suitable. Vision implemented a
small native runtime module: a tagged placed Pawn carries the movable imported
aircraft and calibrated camera, a PlayerController owns input/pause, and a Canvas
HUD supplies Resume/Exit hitboxes. Aircraft motion directly integrates pose and
speed; bank also adds a simple turn. Source preserves EV13, software Lumen and
Maintain Y FOV. DefaultInput.ini contains keyboard axes. Esc remains executable
while paused, flushes held keys, shows a cursor and restores game input on resume.
Exit uses Unreal QuitGame, scoped to the game process.

Signed Microsoft Build Tools 2022 installed successfully side-by-side at
`D:/UnrealBuildTools2022` (17.14, compiler14.44.35229); Windows SDK22621 installed
successfully with no restart. Existing older IDE retained. The first install
attempt rejected an incorrect language flag; corrected command exited0. The
first compile then exhausted C: during shared PCH generation. Milu verified and
moved only this project's generated Intermediate cache to
`D:/PlanesBuildCache/unreal-prototype/Intermediate`, with a junction at the
original path. Vision disabled shared PCH; Compile uses NoUBA. Native compilation
then succeeded in21.79s with zero errors, and Python scene Build/save passed.
