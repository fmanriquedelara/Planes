- Status: done
- Owner: Vision (model import/camera); Milu (evidence/docs/credits)
- Reviewer: Stark

## Scope and acceptance

Replace the Unreal startup Gripen with the existing Eurofighter Typhoon asset.
Preserve native dummy flight, Esc Resume/Exit, lighting fixes and ultrawide Y FOV.
Calibrate the pilot eye to the different geometry; inspect actual normal-game
captures and rerun runtime input/menu tests. Record source, modifications and
attribution. Physical cockpit buttons belong to the imported model; custom menu,
input hints and placeholder display art must not be described as authored or
functional avionics.

## Progress

Vision is using the existing `Godot/Planes/HighResEurofighter.glb` derivative,
checking import axes/units and initial camera before rendering. Gripen assets
remain available. Stark highlighted nested transforms, possible duplicate cockpit
geometry, glass transparency and lower-resolution atlas detail as review risks.

0.1 gives about15.98m length; eye (650,0,180122.5)cm, pitch-4, focal18mm,

display art are retained; only glass/HUD optical treatment is adjusted. No
Gripen-specific synthetic radar or mirror replacements are applied. Existing
Gripen content remains. No original GLB or C++ controls were changed.

3440x1440 Test run exited0 and all14 input/menu checks passed, including Exit.

`eurofighter-menu.png`, `eurofighter-build.json`, and the corresponding
runtime-3440x1440 report/log. Milu, Vision and Stark inspected actual captures.
