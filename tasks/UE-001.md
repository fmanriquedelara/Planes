# UE-001 — Unreal cockpit graphics prototype

- Status: in review (initial visual milestone passed; interactive/performance criteria pending)
- Owner: Vision; Milu coordinates
- Reviewer: Stark
- Dependencies: Unreal Engine 5.8.4 installed locally; existing aircraft assets and reference brief

## Scope

Create a separate Unreal prototype folder. Start with a pilot-eye cockpit view,
daylight atmosphere, clouds, water and terrain. Preserve the Godot and Three.js
projects. Establish a rendered baseline before adding expensive effects.
Vision implements; Stark independently reviews evidence; Milu resolves tradeoffs.

## Acceptance criteria

- A reproducible startup scene places the camera inside the cockpit, with framing
  compared against the supplied references.
- Record engine version, asset provenance, camera, resolution, render scale,
  scalability and graphics settings with rendered evidence.
- Inspect actual GPU-rendered screenshots; assess lighting, cloud depth,
  materials, shadows and aliasing. Source inspection alone is insufficient.
- Measure a standalone flight workload targeting 120 rendered frames per second
  (8.33 ms per frame), separately reporting CPU/GPU timing and frame generation.
  Do not claim this target achieved until measured.
- Keep a higher-quality profile for visual comparison. Test packaged/standalone
  performance independently of editor overhead.
- DLSS is optional; verify official plugin/version/hardware support before use.

## Initial milestone delivery

Final evidence: `unreal-prototype/artifacts/cockpit-final.png` and
`render-final.log`, rendered 2026-11-01 13:18 UTC. Same camera and physical
exposure as the corrected baseline, now with original procedural coastline and
countryside (100 km extent, 32,768 terrain triangles). Native atmosphere/clouds,
simple ocean, authored Gripen textures and illustrative displays are present.
MRQ applies Cinematic scalability during this offline still, as confirmed in the
log; this is distinct from normal game startup scalability. Both Build and Capture
helper commands completed successfully; saves are asserted and Capture verifies
a fresh PNG. Final render had no `Error:`, failed-compile or default-material
fallback lines. Build reports four nonblocking plugin/import warnings.

Stark's final actual-image review: **pass for the bounded initial visual study**.
Pilot-eye framing, clear HUD, restrained mirrors, warm canopy highlights,
visible countryside/coast and continuous horizon are achieved. Milu and Vision
also inspected the same image. No further polish loop is required for delivery.

Remaining work: interactive flight, packaged CPU/GPU timing against 8.33 ms,
performance/quality profiles, fine gauge readability, correct per-island display
UVs, multiscale terrain detail and more natural cloud masses. Large regular field
patches, soft clouds and cropped demonstration displays limit photorealism.
No sustained 120 FPS, authentic avionics, validated flight physics, packaged game
or superiority over the other engines is claimed. Task remains in review because
those original acceptance criteria extend beyond this first visual milestone.
